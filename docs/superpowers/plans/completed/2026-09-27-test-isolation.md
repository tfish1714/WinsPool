# Test Isolation From The Developer's .local_db Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Running `pytest` must never modify a developer's real `.local_db/` (observed: a test overwrote a pick in `.local_db/draft_results.pkl`, corrupting local data, and runs also create an empty `.local_db/` in fresh checkouts). After this change the suite works against a per-run COPY of the real data, and a guard fails the run if the real folder changes anyway.

**Architecture:** (1) One tiny helper `services/local_paths.py::local_db_dir()` that every service/route/script write path uses instead of the literal `pathlib.Path(".local_db")`. With no override it returns exactly `pathlib.Path(".local_db")` (production and dev behavior unchanged). (2) `tests/conftest.py`, at import time (before any test module imports services), copies the developer's real `<repo>/.local_db` (if it exists) into a per-session temp directory and sets the environment variable `WINSPOOL_LOCAL_DB_REDIRECT=<that temp dir>`. (3) The helper honors the redirect ONLY when the cwd-relative `.local_db` would resolve to the real repo folder (`<repo>/.local_db`); tests that `chdir(tmp_path)` and build their own relative `.local_db` keep working untouched. (4) A guard in `pytest_sessionfinish` (controller process only under xdist) compares a fingerprint of the real folder (relative path, size, mtime_ns of every file, plus existence of the directory itself) taken at session start with one at the end and fails the run with a clear message listing the differences.

**Tech Stack:** Python, pytest (+ pytest-xdist), pathlib, shutil.

**Spec:** `docs/superpowers/specs/2026-09-27-offseason-hardening-backlog.md` item B3.

## Review Focus

- Redirect condition: the helper redirects only when `(pathlib.Path.cwd() / ".local_db").resolve()` equals the real repo `.local_db` resolved path; a test that `monkeypatch.chdir(tmp_path)` and uses relative `.local_db` must still see its own tmp folder (there are existing tests relying on this: `tests/test_session_revocation.py`, `tests/test_data_service.py`, `tests/test_db.py`, `tests/test_prediction_results.py`, `tests/test_backfill_features_flag.py`).
- Module-level constants evaluated at import time (`services/cache_service.py::_GAME_PRED_DIR = pathlib.Path('.local_db')`): tests may monkeypatch that name; keep the name and make the default come from the helper at import time (conftest sets the redirect before imports) while remaining monkeypatchable; check every existing reference.
- xdist: each worker imports conftest independently, so each worker makes its own session copy (temp dir per worker), and only the controller does the before/after guard comparison of the real folder; make sure no worker deletes or writes the real folder. Temp copies are deleted at session end.
- The guard must not produce false alarms from the app writing benign files (none should write into the real folder after this change); include creation of `.local_db` when it did not exist at session start as a violation. Provide an escape hatch env var `WINSPOOL_ALLOW_LOCAL_DB_WRITES=1` that downgrades the guard to a warning (for intentional dev flows) and document it.
- Copy cost: copying a large `.local_db` per worker must not make the suite unusably slow; skip files that tests cannot need only if you can prove it safely (default: copy everything, but measure and report time).
- Tests that read the real folder (34 currently environment-dependent tests pass with real data) must still pass when they read the copy.
